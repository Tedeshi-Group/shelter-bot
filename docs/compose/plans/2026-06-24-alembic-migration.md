# Alembic Migration Setup Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use compose:subagent (recommended) or compose:execute to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Set up Alembic for database migrations so schema changes are version-controlled and repeatable.

**Architecture:** Initialize Alembic in the project root, configure it to use the existing SQLAlchemy models and SQLite database, generate an initial migration from current models, and apply it.

**Tech Stack:** Alembic, SQLAlchemy, SQLite

---

### Task 1: Install Alembic and Initialize

**Files:**
- Create: `alembic.ini`
- Create: `alembic/` directory with env.py and script.py.mako

- [ ] **Step 1: Install Alembic in venv (if not already)**

Run on server:
```bash
/opt/shelter-bot/.venv/bin/pip install alembic
```

- [ ] **Step 2: Initialize Alembic**

Run from project root on server:
```bash
cd /opt/shelter-bot && /opt/shelter-bot/.venv/bin/alembic init alembic
```

This creates `alembic.ini` and `alembic/` directory.

- [ ] **Step 3: Update alembic.ini**

Edit `alembic.ini` — set the sqlalchemy.url to use the same DATABASE_URL from config:
```ini
sqlalchemy.url = sqlite:///shelter_bot.db
```

- [ ] **Step 4: Commit**

```bash
git add alembic.ini alembic/
git commit -m "chore: initialize alembic for database migrations"
```

### Task 2: Configure Alembic env.py

**Files:**
- Modify: `alembic/env.py`

- [ ] **Step 1: Update env.py to import models**

Replace the `target_metadata` section in `alembic/env.py`:

```python
from logging.config import fileConfig
from sqlalchemy import engine_from_config, pool
from alembic import context

config = context.config
if config.config_file_name is not None:
    fileConfig(config.config_file_name)

target_metadata = None

import os
import sys
sys.path.insert(0, os.path.dirname(os.path.dirname(__file__)))

from database import Base
from models import User, VoiceSession

target_metadata = Base.metadata
```

- [ ] **Step 2: Commit**


### Task 3: Generate Initial Migration

**Files:**
- Create: `alembic/versions/<auto-generated>.py`

- [ ] **Step 1: Generate migration**

Run on server:
```bash
cd /opt/shelter-bot && /opt/shelter-bot/.venv/bin/alembic revision --autogenerate -m "initial schema"
```

This creates a migration file in `alembic/versions/` with `create_table` for `users` and `voice_sessions`.

- [ ] **Step 2: Review generated migration**

Verify the generated file contains:
```python
def upgrade() -> None:
    op.create_table('users',
        sa.Column('discord_id', sa.BigInteger(), nullable=False),
        sa.Column('username', sa.String(length=255), nullable=False),
        sa.Column('created_at', sa.DateTime(), nullable=False),
        sa.PrimaryKeyConstraint('discord_id')
    )
    op.create_table('voice_sessions',
        sa.Column('id', sa.Integer(), nullable=False),
        sa.Column('user_discord_id', sa.BigInteger(), nullable=False),
        sa.Column('channel_id', sa.BigInteger(), nullable=False),
        sa.Column('joined_at', sa.DateTime(), nullable=False),
        sa.Column('left_at', sa.DateTime(timezone=True), nullable=True),
        sa.Column('duration_seconds', sa.Integer(), nullable=True),
        sa.ForeignKeyConstraint(['user_discord_id'], ['users.discord_id']),
        sa.PrimaryKeyConstraint('id')
    )

def downgrade() -> None:
    op.drop_table('voice_sessions')
    op.drop_table('users')
```

- [ ] **Step 3: Commit**

```bash
git add alembic/versions/
git commit -m "feat: add initial alembic migration"
```

### Task 4: Apply Migration

**Files:** (none — just command)

- [ ] **Step 1: Apply migration on server**

Run on server:
```bash
cd /opt/shelter-bot && /opt/shelter-bot/.venv/bin/alembic upgrade head
```

- [ ] **Step 2: Verify tables exist**

Run on server:
```bash
/opt/shelter-bot/.venv/bin/python -c "
from database import engine
from sqlalchemy import inspect
inspector = inspect(engine)
print('Tables:', inspector.get_table_names())
"
```

Expected output: `Tables: ['users', 'voice_sessions']`

- [ ] **Step 3: Start bot to verify**

```bash
/opt/shelter-bot/.venv/bin/python bot.py
```

Bot should start without `no such table` errors.

- [ ] **Step 4: Commit any final changes**

```bash
git add -A
git commit -m "chore: apply initial migration and verify"
```
